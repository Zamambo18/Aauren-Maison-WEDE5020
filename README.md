## Project Overview
Aauren Maison is a luxury fashion boutique located at Oceans Mall, Umhlanga, Durban. This website proposal and Part 1 implementation aims to create an elegant, responsive online presence for the boutique, showcasing haute couture, bespoke styling services, and exclusive collections. The site targets high-end clientele seeking luxury fashion in KwaZulu-Natal.

## Website Goals/Objectives
1. Establish a premium digital brand identity for Aauren Maison
2. Showcase boutique location at Oceans Mall with visual appeal
3. Provide clear information on services: couture, bespoke styling, personal shopping
4. Enable customer enquiry and contact functionality
5. Create a fully responsive website accessible on mobile and desktop
6. Maintain professional GitHub workflow with regular commits

## Key Features (Part 1)
- Responsive 5-page structure (Home, About, Services, Enquiry, Contact)
- Luxury hero section with boutique imagery
- Modern CSS styling (css/style.css)
- Optimized image folder structure (images/boutique.jpg)
- Semantic HTML5
- GitHub Pages deployment
